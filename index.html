Dados do mês

Rótulo e orçamento valem para os dois modelos abaixo.

Importar de uma planilha

Envie um .xlsx ou .csv com o mesmo layout das abas "Dados" e "Dados (Influenciadores)" da sua planilha original (linha de cabeçalho com os nomes, seguida das 5 linhas de métricas). Se houver uma aba "Solver", o orçamento também é importado.

Pesos por métrica

Importância de cada métrica na função-objetivo — usada nos dois modelos.

Modelo A — Influenciadores × Encartes

Quanto cada métrica rende por R$ 1,00 investido em cada tipo.

Modelo B — influenciadores

Quanto cada métrica rende por R$ 1,00 investido em cada influenciador. Renomeie, adicione ou remova linhas conforme sua lista mudar.

Modelo C — encartes

Quanto cada métrica rende por R$ 1,00 investido em cada encarte. Renomeie, adicione ou remova linhas conforme sua lista mudar.

Meses salvos

Toque em um mês para ver os detalhes aqui embaixo. Use "ocultar"/"exibir" para incluir ou remover o mês dos gráficos e tabelas do comparativo — os dados continuam salvos mesmo ocultos.

Mês em destaque

Os valores de exemplo já preenchidos vieram da sua planilha original — substitua pelos dados reais de cada mês. O cálculo replica a otimização do Solver (alocação fracionária ótima respeitando o teto de diversificação e o orçamento).
